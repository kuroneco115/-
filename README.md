# かんたんカレンダー

スマホで使いやすい、シンプルなカレンダーWebアプリです。

## 機能
- 月間カレンダー
- 予定の追加・編集・削除
- キーボードによる簡単入力
- 対応ブラウザで日本語音声入力
- 自然な入力例：「明日の15時に数学」
- ブラウザのローカルストレージに保存
- スマホ表示対応
- GitHub Pages対応
- PWAとしてホーム画面に追加可能

## GitHub Pages
1. このフォルダの中身をGitHubリポジトリにアップロード
2. Repository → Settings → Pages
3. Sourceを「Deploy from a branch」
4. Branchを `main` / `/ (root)` にしてSave
5. 表示されたURLをスマホで開く

## 注意
予定データは現在のブラウザ内に保存されます。別の端末やブラウザとは自動同期されません。
音声入力はブラウザの音声認識機能に依存します。
